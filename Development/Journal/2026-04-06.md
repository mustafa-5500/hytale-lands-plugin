Starting today I will keep a daily Dev journal, to try and encourage progress daily, and be able to record our progress over time and any offshoot ideas we get. For example today we got the idea to use our land selection code in a little plugin for The Build Guild, to select regions and represent them as a set of numbers, coordinate pairs, each representing the min and max of a cuboid region. This is to allow written documents to be linked to certain regions, allowing better integration of lore and building. All this plugin needs is a way to make selections, including adding and removing cuboid regions from the selection, visualizing the selections, and giving a text representation of the selection. Even though this plugin is meant for hytale, we could easily reuse the code for minecraft, as they are both java plugins. For the minecraft repo, we would eventually create multiple branches one for each type of minecraft server api. Not only would this make sure it is compatible with different minecraft servers, it will also help us learn about each api and develop resources to better access them.
